# 修复无目录时残留歌曲显示

## Goal

让“本地歌曲”只反映当前已配置本地音乐目录中的有效媒体，而不是把全局媒体元数据缓存当作本地库成员；清除或修复旧版 Windows 扩展路径身份遗留，确保无目录时进入音乐库得到真实空状态。

用户价值：删除或未配置歌曲目录后，不再看到历史扫描快照；重新添加目录时仍能正确扫描、去重和清理失效记录。完整清理会按用户确认删除匹配播放历史，但绝不删除磁盘上的歌曲。

## Confirmed Facts

- 当前运行数据库的 `library_roots` 为空，但 `media_items` 有 391 条记录，其中 371 条为本地媒体、20 条为远程媒体。
- 371 条本地记录在 2026-05-03 的 11 秒内批量写入，全部带时长、mtime 和大小，369 条带封面；只有 12 首进入过播放会话，因此它们是历史扫描快照，不是最近播放动态生成的列表。
- 这些旧记录都来自 `D:\移动云盘挂载\15869685321\Music`。该目录当前有 593 个受支持媒体文件，因此 371 条记录只是旧时点的部分快照。
- 360 条旧记录使用遗留 `media_id` 形式 `//?/d:/...`，但当前 `media_id_for_path()` 会把对应 `\\?\D:\...` 路径规范化为 `d:/...`；只有 11 条记录已被按当前身份合同调和。
- `delete_local_media_not_in_root()` 根据 `source_path` 重新计算规范化 ID，却按该计算值删除 `media_items.media_id`，因此无法删除遗留 ID 行；目录根仍会被删除，留下孤儿媒体。
- `list_library_track_summaries()` 无条件读取全部 `media_items`，不按当前目录成员关系过滤，也不排除远程媒体。
- 前端独立加载目录根和歌曲摘要；离线侧栏按既有产品合同保持稳定入口，因此本任务必须让无目录场景渲染空状态，而不是隐藏导航入口。
- 当前相关未提交前端改动集中在离线导航、本地歌单和动效，不包含上述后端身份、清理和摘要查询逻辑；本任务必须保留这些用户改动。
- 用户复核后撤回“保留孤儿元数据”的选择：升级/启动时应自动清理可判定为不属于任何有效本地目录的本地媒体记录及其数据库引用；删除目录时也应保持同一清理语义。清理数据库不得删除磁盘歌曲。
- 用户进一步确认采用完整清理语义：匹配媒体的播放历史、播放会话和持久化队列也应删除，不采用仅将 `media_id` 置空的保留方案。当前数据库预计涉及 38 条播放历史和 20 条播放会话。

## Requirements

1. `library_roots` 为空时，本地歌曲、专辑、艺术家和文件夹数据必须为空；全局媒体缓存、播放历史、队列或在线媒体记录不得单独构成本地库成员。
2. 配置根后，本地库查询只返回属于当前有效本地或 WebDAV 根的媒体；未属于有效根的远程媒体和目录外本地媒体不得混入。
3. Windows 扩展路径、普通盘符路径及斜杠变体必须映射到同一规范身份；清理逻辑必须按数据库中实际存储的媒体主键更新引用和删除记录，不得因遗留 `//?/` ID 与当前规范 ID 不同而漏删。
4. 删除本地目录时，必须按实际存储的媒体主键删除该目录的库记录，不能用重新计算但可能不同的 ID 代替数据库主键。
5. 成功重扫目录时，失效记录清理必须同时覆盖规范 ID 和遗留 ID，且不得误删其他目录、远程媒体或仍被本次扫描看到的文件。
6. 数据修复不得删除磁盘上的音频文件。移除媒体记录时，必须在同一事务中删除匹配的播放历史、播放会话、持久化队列项、本地歌单成员和其他依赖记录，清理歌单封面等可空引用，再删除封面缓存与媒体主记录；不得留下悬空身份或路径引用。
7. 不得通过清空整个 `app_state.db`、重置用户设置或依赖前端过滤缓存来掩盖问题。
8. 离线侧栏稳定入口、导航历史和现有空状态合同保持不变；本任务只修正本地库数据真相及其 API 输出。
9. 修复必须兼容已有数据库和新建数据库，且启动、删除目录、重新添加目录、重扫四条路径均可重复执行。
10. 可判定为不属于任何当前有效本地目录的 `source_kind='local'` 媒体记录必须在受版本控制、可重复执行的修复事务中删除；远程媒体不按本地文件路径规则误删，但同样不得在没有有效库成员关系时混入本地库视图。

## Acceptance Criteria

- [x] 在存在全局本地/远程 `media_items` 但 `library_roots` 为空的数据库夹具中，歌曲摘要、专辑、艺术家和文件夹均返回空数据。
- [x] 配置一个本地目录后，只返回该目录内媒体；目录外本地记录和远程记录不出现在本地库摘要及分组结果中。
- [x] 使用 `source_path='\\?\D:\Music\a.flac'`、遗留 `media_id='//?/d:/music/a.flac'` 的回归夹具，删除 `D:/Music` 根可以删除对应媒体记录和受约束引用，并报告正确删除数量。
- [x] 重扫清理对规范 ID 与遗留 ID 都有效，同时保留本次已看到的媒体和其他目录媒体。
- [x] 现有 371 条本地历史快照及其封面缓存、本地歌单成员、38 条匹配播放历史、20 条匹配播放会话和匹配持久化队列项在升级修复事务中清理；修复后当前无目录数据库的本地库计数为 0，磁盘上的 593 个媒体文件不受影响。
- [x] 重新添加当前音乐目录并完成扫描后，库数据按当前文件系统重新建立，不复用 371 条旧快照作为目录成员真相。
- [x] 现有规范路径删除测试继续通过，并新增遗留扩展路径、无目录查询、目录外媒体和远程媒体覆盖。
- [x] 显式删除目录后，该目录的媒体元数据、历史、会话、持久化队列和其他依赖引用被清理；与其他仍有效目录共享的媒体不得被误删。
- [ ] 前端在无目录时保留离线音乐库入口并展示既有空状态，不显示残留歌曲。　【判定：归档材料无前端运行时证据，不可重建】
- [x] 后端聚焦测试、前端相关测试、Rust 格式/静态检查和桌面 TypeScript 检查通过。

## Out of Scope

- 删除或移动用户磁盘上的音频文件。
- 改变离线侧栏目的地、顺序、动效或持久化合同。
- 重做在线媒体、播放历史、队列或本地歌单产品能力。
- 以全库数据库重置作为发布修复方案。
